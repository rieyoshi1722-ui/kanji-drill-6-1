# kanji-drill-6-1

小学6年生（上・下）の漢字ドリル。上は10〜12、下は1〜3の漢字を、読み・書きの4択、紙に書く練習、スマホに書く「デジタル書き」、50問テストで練習できます。

- `index.html` だけで動きます（インストール不要）
- 「まちがえた問題」や「出た問題」の記録は、使っているブラウザの中に保存されます
- 「下」は準備中

## お手本データについて

「デジタル書き」のお手本の線データは、[Hanzi Writer の日本語データ](https://github.com/chanind/hanzi-writer-data-jp)（[animCJK](https://github.com/parsimonhi/animCJK) と [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) が元）を使っています。
このデータは GNU LGPL v3 などのライセンスで配布されています。詳しくは元のリポジトリの `licenses` フォルダを見てください。
